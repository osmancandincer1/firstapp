# Nokuzo

Her akşam dokuzda, dokuz kişi. Ürün ve teknik şartname: [APP.md](APP.md) (tek doğruluk kaynağı).

## Hızlı başlangıç

```bash
npm install          # kökte bir kez
npm run mobile       # Expo geliştirme sunucusu → telefonda Expo Go ile QR kodu okut
npm run web          # tanıtım sitesi → http://localhost:3000
npm run ci           # tip denetimi, lint, biçim, i18n, birim testleri
```

Ayrıntılar: [docs/SETUP.md](docs/SETUP.md) · Mimari: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · Test sonuçları: [docs/TEST_REPORT.md](docs/TEST_REPORT.md) · Kararlar: [docs/DECISIONS.md](docs/DECISIONS.md)
